# Python

# WEEK 1. 파이썬 소개

Python은 문법이 간결하고 읽기 쉬운 프로그래밍 언어입니다. 다른 프로그래밍 언어에 비해 작성해야 하는 코드의 양이 적고 이해하기 쉬워 프로그래밍을 처음 배우는 사람들이 많이 사용하는 언어입니다.

또한 웹 개발, 데이터 분석, 인공지능 등 다양한 분야에서 활용되고 있어 활용 범위가 매우 넓습니다. Python 프로그램을 작성하고 실행하는 방법을 익히며 프로그래밍의 기본 개념을 학습하였습니다.

예를 들자면

```python
print("Hello Python")
```

# WEEK 2. 변수와 수식

변수는 데이터를 저장하기 위한 공간으로 프로그램에서 값을 기억하고 활용하기 위해 사용됩니다. 변수에 저장된 값은 프로그램 실행 과정에서 변경될 수 있으며 계산이나 데이터 처리에 활용됩니다.

수식은 변수와 연산자를 이용하여 계산을 수행하는 식입니다. 다양한 연산을 통해 원하는 결과를 얻을 수 있으며 프로그래밍에서 가장 기본이 되는 개념 중 하나입니다.

예를 들자면

```python
x = 10
y = 20

result = x + y

print(result)
```

# WEEK 3. 조건문

조건문은 특정 조건의 참과 거짓을 판단하여 프로그램의 실행 흐름을 결정하는 문법입니다. 조건에 따라 서로 다른 결과를 출력하거나 다른 작업을 수행할 수 있습니다.

조건문을 사용하면 프로그램이 단순히 순서대로 실행되는 것이 아니라 상황에 따라 적절하게 동작하도록 만들 수 있습니다.

예를 들자면

```python
age = 20

if age >= 19:
    print("성인입니다.")
else:
    print("미성년자입니다.")
```

# WEEK 4. 반복문

반복문은 동일한 작업을 여러 번 수행할 때 사용하는 문법입니다. 반복문을 사용하면 같은 코드를 반복해서 작성할 필요가 없으며 프로그램을 더욱 효율적으로 작성할 수 있습니다.

반복문은 데이터 처리나 계산 작업 등 다양한 상황에서 활용되며 프로그래밍에서 매우 중요한 역할을 합니다.

예를 들자면

```python
for i in range(5):
    print(i)
```

# WEEK 5. 함수

함수는 특정 기능을 수행하는 코드들의 집합입니다. 프로그램을 작성하다 보면 동일한 작업을 여러 번 수행해야 하는 경우가 있는데 함수를 사용하면 필요한 기능을 한 번 정의한 후 반복적으로 사용할 수 있습니다.

함수를 활용하면 프로그램을 체계적으로 구성할 수 있으며 코드의 재사용성을 높일 수 있습니다.

예를 들자면

```python
def greet():
    print("안녕하세요")

greet()
```

# WEEK 6. 리스트

리스트는 여러 개의 데이터를 하나의 변수에 저장할 수 있는 자료형입니다. 데이터를 순서대로 저장하며 필요한 위치의 데이터를 쉽게 사용할 수 있습니다.

많은 양의 데이터를 효율적으로 관리할 수 있기 때문에 Python에서 가장 많이 사용되는 자료형 중 하나입니다.

예를 들자면

```python
fruits = ["apple", "banana", "orange"]

print(fruits)
```

---

# WEEK 7. 튜플, 세트, 딕셔너리

튜플, 세트, 딕셔너리는 리스트와 함께 사용되는 대표적인 자료구조입니다. 각각의 자료형은 데이터를 저장하는 방식과 특징이 다르며 상황에 따라 적절하게 활용할 수 있습니다.

이러한 자료구조를 이용하면 데이터를 보다 효율적으로 저장하고 관리할 수 있습니다.

예를 들자면

```python
student = {
    "name": "Kim",
    "age": 20
}

print(student["name"])
```

# WEEK 8. 객체와 클래스

객체와 클래스는 객체 지향 프로그래밍의 핵심 개념입니다. 클래스는 객체를 생성하기 위한 설계도 역할을 하며 객체는 클래스를 바탕으로 만들어진 실제 데이터입니다.

객체 지향 프로그래밍을 활용하면 프로그램을 보다 구조적으로 설계할 수 있으며 복잡한 기능도 체계적으로 구현할 수 있습니다.

예를 들자면

```python
class Student:
    def __init__(self, name):
        self.name = name

student1 = Student("Kim")

print(student1.name)
```
